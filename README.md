# Delta 机器人仿真平台

这是一个基于 Python 开发的 Delta 并联机器人 3D 仿真与控制平台。项目集成了逆运动学求解、物理 PID 控制、空间避障轨迹规划，以及基于大模型（DeepSeek）的自然语言指令解析与绘图功能。

## 🌟 核心功能

- **模式 1：点对点运动** - 手动输入 (X, Y, Z) 目标坐标，机器人自动规划平滑移动轨迹。
- **模式 2：基础图形绘制** - 一键自动生成并绘制圆形、三角形、五角星等预设轨迹。
- **模式 3：自然语言控制** - 输入自然语言指令（如“画一只猪”），大模型自动解析为几何轨迹 JSON 并执行绘制。
- **模式 4：工业场景模拟** - 演示物料从传送带抓取、搬运并放置到料盒的门型运动轨迹。
- **扩展模块**：
  - **PID 实时调节**：动态调整 Kp, Ki, Kd 观察物理响应。
  - **工作空间可视化**：后台多线程计算并渲染机器人可达空间点云。
  - **自动避障**：启用避障球体后，机器人会自动计算安全途经点绕开障碍物。
